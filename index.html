What you can do with it

Hundreds of ready-made use cases

Realistic, vendor-accurate log samples spanning Windows, AWS, Azure, GCP, M365, Google Workspace, Okta, Duo, and more — tagged by MITRE ATT&CK tactic. Nothing to author yourself.

One-click replay

Replay All, Replay Selected, or run a whole tactic folder in sequence with the ▶ button on its header.

Realistic timing

Set a global delay between events, or a per-event delay to simulate a real attack's pacing.

Multiple targets

Dev / UAT / Production, or separate tenants — each use case remembers which target it last used.

Auto-timestamping

Every replayed log's timestamp is rewritten to now, so it shows up as live traffic in your SIEM regardless of when the sample was captured.

Verify in Exabeam

Query the Search API after a replay to confirm events landed and parsed, with per-field inspection and saved verify history.

Bring your own logs

Import from .log/.txt, .csv, .json, or paste directly, alongside the bundled library.

Backup & restore

Back up your whole library — use cases, folders, webhooks, settings — as a single file, and restore it later.

Getting started

  1. Install and open Echo. On Windows, run the .exe and follow the installer. On macOS, open the .dmg and drag Exabeam Echo into Applications. macOS: if you see "cannot be opened because the developer cannot be verified," open System Settings → Privacy & Security and click Open Anyway next to the app name, then open it again. This is a one-time step per install — the build is ad-hoc signed but not yet notarized with an Apple Developer ID.
  2. Create a Webhook Cloud Collector in Exabeam, in RAW format. In your Exabeam tenant, go to Collectors → Cloud Collectors → New Collector → Webhook, give it a name, and for Format choose RAW — not Json. Click Install, then copy the Bearer token and endpoint URL shown on the install screen; you'll need both in the next step. Why RAW, not Json: Echo always sends events as plain text. A RAW collector accepts any body — plain text, JSON, XML, whatever the use case contains — while a Json collector rejects anything that isn't valid JSON with an HTTP 400. One RAW collector covers the entire bundled library, so you only need to do this once.
  3. Add that collector to Echo as a webhook target. Back in Echo, open Settings and add a new Webhook using the endpoint URL and Bearer token you just copied.
  4. (Optional) Configure the Search API in Settings if you want Echo to confirm, after each replay, that your logs actually landed and parsed. This needs OAuth client credentials from your Exabeam tenant and the name you gave the collector in Cloud Collectors.
  5. Pick a use case and replay it. Choose one from the sidebar (organized by MITRE ATT&CK tactic) and click Replay All. Watch the Replay tab for per-event HTTP status — if Search API is configured, verification starts automatically once events have had time to land.
